hstin packages

Signed apt and dnf repositories of the projects of hstin. The packages themselves are the files of each project's GitHub releases.

Projects

    @PROJECTS@

By hand (replace PROJECT)

# Debian, Ubuntu: one component per project
sudo curl -fsSLo /usr/share/keyrings/hstin.gpg @BASE@/keys/hstin.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/PROJECT.sources @BASE@/apt/PROJECT.sources
sudo apt-get update && sudo apt-get install PROJECT

# Fedora, RHEL: one repository per project
sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-hstin @BASE@/keys/hstin.asc
sudo curl -fsSLo /etc/yum.repos.d/PROJECT.repo @BASE@/rpm/PROJECT/PROJECT.repo
sudo dnf install PROJECT

Packages may bring their repository file and key along, so later changes of either arrive with updates.

Keys

Repository key: keys/hstin.asc. Projects with signed update metadata publish it under PROJECT/updates/, checked against keys built into the project.

Source: github.com/hstin-de/pkgs.
