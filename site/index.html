hstin packages

One signed apt and dnf repository with the packages of the projects of hstin. Set it up once, then install any of them with your package manager.

Debian, Ubuntu

curl -fsSLo /tmp/hstin-repo.deb @BASE@/hstin-repo.deb
sudo apt install /tmp/hstin-repo.deb && sudo apt update
sudo apt install otterlink

Fedora, RHEL

sudo dnf install @BASE@/hstin-repo.rpm
sudo dnf install otterlink

The package hstin-repo holds the repository's source and key, so a change of either arrives as an update; removing it removes the repository.

Script

curl -fsSLO @BASE@/install.sh && less install.sh && sudo sh install.sh otterlink

By hand

# Debian, Ubuntu
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/hstin.gpg @BASE@/keys/hstin.gpg
printf 'Types: deb\nURIs: @BASE@/apt\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/hstin.gpg\n' |
  sudo tee /etc/apt/sources.list.d/hstin.sources
sudo apt update

# Fedora, RHEL
sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-hstin @BASE@/keys/hstin.asc
sudo curl -fsSLo /etc/yum.repos.d/hstin.repo @BASE@/rpm/hstin.repo
