hstin packages

One signed apt and dnf repository with the packages of the projects of hstin. Set it up once, then install any of them with your package manager.

Debian, Ubuntu

cd "$(mktemp -d)" && curl -fsSLO @BASE@/hstin-repo.deb && sudo apt install ./hstin-repo.deb && sudo apt update
sudo apt install otterlink

Fedora, RHEL

sudo dnf install @BASE@/hstin-repo.rpm
sudo dnf install otterlink

Script

cd "$(mktemp -d)" && curl -fsSLO @BASE@/install.sh && less install.sh && sudo sh install.sh otterlink

It installs hstin-repo, then the packages named.

The key

The package hstin-repo holds the repository's source and key, so a change of either arrives as an update; removing it removes the repository. Packages of this repository never replace a package of your distribution with the same name.

Fingerprint: @FINGERPRINT@ (keys/hstin.asc; also in the README of github.com/hstin-de/pkgs). Check the installed key with gpg --show-keys /usr/share/keyrings/hstin.gpg or rpm -qi gpg-pubkey.
